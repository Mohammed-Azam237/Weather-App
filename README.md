# Weather-App

This Weather App is a responsive web application built using HTML, CSS, and JavaScript that allows users to fetch and view real-time weather information for any city around the world. It utilizes a public weather API (such as OpenWeatherMap) to display key weather details including temperature, humidity, weather conditions, wind speed, and more. The UI is clean and user-friendly, with error handling for invalid city names and smooth animations for better UX.

Features:

Search for current weather by city name

Displays temperature, weather condition, humidity, and wind speed

Responsive design for mobile and desktop

Integrated with a weather API (like OpenWeatherMap)

Error message display for invalid input
